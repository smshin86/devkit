이 프로젝트에서 앞으로 기능을 고치고 붙일 거야. 지금은 코드를 바꾸지 말고, 먼저 프로젝트를 살펴만 봐 줘.
지출을 세 단계로 나눠 넣게 해 줘. 1단계 화면에서 이름과 금액을 넣고, 2단계 화면에서 나눌 사람을 고르고, 3단계 화면에서 확인한 뒤 저장하면 좋겠어.
프로젝트 비밀번호를 바꿀 때 지금 비밀번호를 한 번 더 넣게 해 줘.
지출 목록 화면에 지출 이름으로 찾는 검색 칸을 하나 더해 줘.
지출 목록을 엑셀 파일로 내려받을 수 있게 해 줘.
지출 목록을 달력 모양으로도 볼 수 있게 해 줘. 날짜 칸마다 그날의 지출이 보이면 좋겠어.
정산할 때 나눈 금액을 10원 단위로 반올림해서 계산하게 바꿔 줘.
지출에 영수증 사진 파일을 올려서 붙여 둘 수 있게 해 줘.
지출 목록을 금액이 큰 순서로도 볼 수 있게 해 줘.
