# 화면 표 쓰기

## 언제 읽는가
살펴(분석해) 달라는 부탁일 때만, 길 안내(`first-guide.md`)를 쓰면서 읽는다. 큰 일의 길(이번에 건드릴 곳만 쓸 때)에서는 읽지 않는다.

## 쓰는 자리
`.devkit/screens.md`. 한 줄에 화면 하나다. 다 쓰면 길 안내 `## 어디에 무엇이`의 `화면 하나하나` 줄에 이 파일과 수를 적는다.

## 틀
제목과 칸은 고정이다(다음 대화가 같은 자리에서 찾는다).
```
# 화면 표

- 쓴 때: <YYYY-MM-DD> · 화면 <n>개: `<화면 파일을 센 명령>` · 주소 <m>개: `<주소를 센 명령>`
- 통째로 읽지 않고 화면 이름·주소로 검색한다. `?`는 못 찾은 칸이다.

| 화면 | 화면 파일 | 주소 | 받는 코드 |
|---|---|---|---|
| <무슨 화면인지 한 마디> | `<경로>` | `<주소>` | `<경로:줄>` |
```

## 규칙
- 화면 파일을 검색 명령으로 모두 뽑고, 주소를 받는 코드도 검색 명령으로 모두 뽑아 맞댄다. 파일을 하나하나 열지 않고 검색 출력으로 맞댄다. 검색은 화면·코드 파일 종류만 골라서(`--include`·`-g` 같은 것) 한다. 주소가 설정 파일에만 적히는 틀이면 그 파일 하나를 이름으로 짚는다 — 설정 파일 종류를 통째로 검색하지 않는다(접속 정보가 딸려 온다). 그 파일도 먼저 비밀번호·계정·접속을 뜻하는 낱말과 `://`…`@` 꼴을 대소문자 없이 찾아 수만 세고(`-ci`), 0이 아니면 줄을 찍지 않고 받는 코드 칸을 `?`로 둔다. 0이면 주소를 적는 꼴로만 찾는다. `first-guide.md`의 "읽지 않는 것"에 든 파일의 줄은 끌어오지 않는다.
- 화면 파일은 센 수만큼 다 적는다 — 골라 적지 않고, 없는 파일은 적지 않는다. 머리에 적은 수·센 명령이 낸 수·표의 화면 줄 수가 같아야 한다. 다른 화면에 끼워 쓰는 조각(머리·꼬리·메뉴)도 적고 한 마디에 "조각"이라고 쓴다. 다 못 적으면 적은 수와 센 수를 머리에 둘 다 쓰고, 못 적은 곳을 길 안내 `## 못 본 것`에 적는다.
- 화면이 파일 하나에 여럿이면(부품으로 그리는 틀) 화면을 그리는 부품을 모두 세어 부품마다 한 줄로, 화면 파일 칸에 `경로:줄`을 적는다 — 이때 머리의 수는 부품 수다(센 명령도 부품을 세는 명령으로 쓴다). 작은 부품도 빼지 않고 "조각"이라고 쓴다.
- 주소 없이 앱 안에서 바뀌는 화면이면 주소 칸에 "앱 안"이라 쓰고, 받는 코드 칸에 그 화면을 부르는 줄을 적는다.
- 받는 코드 칸은 그 주소를 받아 처리하는 코드에서 그 주소가 적힌 줄의 `경로:줄`이다 — 그 주소로 가는 링크나 문서의 줄이 아니다. 화면 없이 자료만 주는 주소도 한 줄씩 적고 화면 칸과 화면 파일 칸을 `—`로 둔다.
- 한 마디는 파일 이름·제목에서 딴다. 못 맞댄 칸은 짐작하지 않고 `?`로 둔다.
- 경로는 프로젝트 맨 위에서부터 적는다(검색에 걸리게). 값은 옮기지 않는다 — 주소에 섞인 계정·열쇠·토큰(`://` 뒤 `@` 앞, `?` 뒤, 경로 속 긴 무작위 글자)은 빼고 이름과 자리만 적는다. `first-guide.md`의 "읽지 않는 것"은 여기서도 같다.
