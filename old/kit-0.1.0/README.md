# devkit

이미 있는 프로젝트에서 AI에게 무엇을 만들어 달라고 할 때, 요청한 것만 맞게 만들도록 돕는 스킬 묶음이다.
Claude Code와 Codex에서 쓴다.

## 깔기
이 폴더에서 한 번 친다. 그 뒤 새 대화를 연다.

    python3 install.py

(Windows에서 `python3`이 없다고 나오면 `python install.py`.)
명령을 치는 것이 낯설면, 이 폴더에서 Claude Code나 Codex를 열고 "install.py를 실행해 줘"라고 해도 된다.
Claude Code와 Codex 중 컴퓨터에 있는 쪽에 깔린다. 다시 치면 새 판으로 바뀐다.
깐 뒤에 이 폴더를 옮기거나 지우면 다시 깔아야 한다.

## 지우기

    python3 install.py --remove

## 쓰기
따로 부를 필요 없다. 평소처럼 "이 화면에 무엇을 넣어 주세요"라고 요청하면 된다.

| 스킬 | 하는 일 |
|---|---|
| 화면 지도 (`screen-map`) | 화면을 고치기 전에, 그 화면이 어떤 틀에 싸여 있고 어떤 스타일·스크립트가 이미 불러와져 있는지 찾는다 |
| 만들 것 목록 (`build-list`) | 고치기 전에 "만들 것 / 요청에 없지만 정한 것 / 안 만들 것"을 적고, 끝난 뒤 맞춰 보고, 다른 눈에게 검토를 받는다 |
| 동시에 만들기 (`parallel-build`) | 서로 기다릴 필요가 없는 일을 동시에 만들고, 합친 뒤 합친 것 전체를 한 번 본다 |

## 필요한 것
Python 3, 그리고 Claude Code나 Codex.
